# Open source exceptions

Independence rule of the project owner (effective 2026-11-01): MarkDown++ ships only code
that its authors wrote, understand and test themselves. Every third-party component the
project still uses is an accepted exception and is listed here; a dependency in
`package.json` that is missing from this file is a defect. Components in the category
"Other" always carry the plan "Rebuild planned" and an open task in
[cleanup.md](cleanup.md).

- Direct dependencies (runtime and dev), bundled fonts and GitHub Actions are maintained by
  hand below. Versions are the exact pins from `package.json`; licenses are taken from each
  package's own `package.json` metadata.
- The full transitive list of packages bundled into the app, with their license texts, is
  generated by `npm run licenses` into [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).
  It is generated; do not edit it by hand.
- Categories: Toolchain and runtime, Crypto and TLS, Platform requirement, Mandated by spec
  (the project specification fixes the component), Other.
- Dev dependencies are build, lint and test tools. They are not part of the shipped app
  bundle (Vite bundles only runtime code into `out/`, `node_modules` is excluded from
  `app.asar`, see `electron-builder.yml`).
