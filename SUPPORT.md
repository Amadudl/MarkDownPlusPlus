# Getting help

Thanks for using MarkDown++! Here is where to find answers.

## Read the documentation

| Question                                  | Where to look                                                                              |
| ----------------------------------------- | ------------------------------------------------------------------------------------------ |
| How do I install, update or uninstall it? | [Installation](docs/installation.md)                                                       |
| How do I do X in the editor?              | [User guide](docs/user-guide.md) and [tutorial](docs/tutorial.md)                          |
| What is the shortcut for …?               | [Keyboard shortcuts](docs/keyboard-shortcuts.md), or `⌘/` / `Ctrl+/` in the app            |
| How do I create or share a theme?         | [Theming](docs/theming.md)                                                                 |
| Where are my settings stored?             | [Installation → Where settings are stored](docs/installation.md#where-settings-are-stored) |
| Something looks broken                    | [User guide → Troubleshooting](docs/user-guide.md#troubleshooting)                         |

Inside the app, **Help → Documentation** opens the documentation and the command palette
(`⌘⇧P` / `Ctrl+Shift+P`) lists every command.

## Ask a question or report a problem

- **Bugs** — open a [bug report](https://github.com/Amadudl/MarkDownPlusPlus/issues/new?template=bug_report.yml).
  Include your version (**MarkDown++ → About MarkDown++** on macOS, **Help → About
  MarkDown++** on Windows and Linux, or **Settings → About**), OS, and the smallest
  Markdown that reproduces the problem.
- **Ideas** — open a [feature request](https://github.com/Amadudl/MarkDownPlusPlus/issues/new?template=feature_request.yml).
- **Security issues** — never in public; follow [SECURITY.md](SECURITY.md).

Please search [existing issues](https://github.com/Amadudl/MarkDownPlusPlus/issues?q=is%3Aissue)
first — your question may already be answered.
